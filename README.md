# Java Calculator - Method Overloading

A simple Java application demonstrating compile-time polymorphism through method overloading in Java.

## Features

- Overloaded `sum` methods handling different parameter counts and types (`int`, `double`).
- Demonstrates compile-time method resolution in Java.
- Includes comments explaining invalid overloading anti-patterns (such as differing only by return type or parameter names).

## Files

- `Calculator.java`: Contains the overloaded calculator methods.
- `CalculatorTest.java`: Test driver invoking the different method variants.

## How to Run

1. Compile the Java files:
   ```bash
   javac Calculator.java CalculatorTest.java
   ```

2. Run the program:
   ```bash
   java CalculatorTest
   ```
